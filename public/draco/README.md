# Yerel Draco çözücü

Bu dosyalar three@0.183.2 paketinin examples/jsm/libs/draco/gltf klasöründen alınmıştır. GLB modelleri KHR_draco_mesh_compression kullandığı için ModelLoader /draco/ yolunu kullanır.

Draco: Google, Apache License 2.0.
Kaynak ve lisans: https://github.com/google/draco
three.js: https://github.com/mrdoob/three.js (MIT).

draco_wasm_wrapper.js ve draco_decoder.wasm birlikte kullanılır; draco_decoder.js JavaScript çözücüsüdür.
